# resources

运行时资源。资源通过 `assets` 分区打包，不整包加载到内存。

## 目录

- `fonts/`：中文 16/24 px 子集、数字等宽字体；记录来源与授权。
- `images/`：表情、图标、背景，RGB565/PNG。
- `animations/`：状态精灵表与动作帧序列。
- `audio/`：提示音、警报音、音效；TTS 不落盘到本目录。
- `i18n/`：中英文文案，UTF-8，键名与代码一致。

## 规则

- 每个资源记录来源、授权、目标尺寸/格式、生成脚本。
- 不在运行时动态分配每帧图像；使用预解码/精灵表。
- 缺字、缺图、解码失败要有回退，不崩溃。
- 可商用字体与音效必须明确授权；未确认的资源只用于原型。

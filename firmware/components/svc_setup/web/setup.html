栖团设备设置

连接网络，开始陪伴。

正在读取设备状态…

1. 连接家里的 Wi-Fi

使用 2.4 GHz 网络。开放网络的密码可留空。

2. 开通小智语音

Wi-Fi 保存成功后，获取绑定码，再到小智平台添加设备。已有绑定时会直接获取连接配置。

打开小智控制台

此热点没有互联网。手机可暂时切回家庭 Wi-Fi 或移动网络完成绑定，再连回屏幕显示的设备热点查看结果。

也可以稍后配置，先使用宠物主页。

管理台接入（可选）

仅在需要接收管理台消息时填写。这些是 Broker 的设备账号，不是管理台登录令牌。

设置入口约 15 分钟后关闭。以后可从设备的“网络设置”重新进入，不会清空成长存档。

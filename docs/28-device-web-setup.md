# 设备热点配网与小智绑定

适用于 ESP32-S3 基础发行硬件，`CONFIG_PET_SETUP_PORTAL_ENABLED=y`。设备插电后自行联网、运行；手机或电脑只用于首次设置，Mac 不承担日常转发。

## 手机设置

1. 未保存 Wi-Fi 的设备首次启动进入“网络设置”。连接屏幕显示的设备热点（默认 `Qitomo-xxxx`，密码为随机 12 位；可在页面第 2 节改为自定义名称或固定密码），输入屏幕上的密码；手机提示无互联网时选择保持连接。
2. 浏览器手动打开 `http://192.168.4.1`。选择或填写家庭 **2.4 GHz** Wi-Fi，输入密码并点“连接并保存”。设备取得 IP 后才保存；连接失败保留旧凭据，可以重试。
3. 如使用小智官方平台，点“获取小智绑定码”。出现数字码后，在 [xiaozhi.me](https://xiaozhi.me) 添加设备并输入该码。手机可暂时离开设备热点改用移动网络，也可使用另一台联网电脑；开发板继续通过家庭 Wi-Fi 核对绑定结果。
4. 等待设备页面提示“语音配置已保存”，再点“完成，返回宠物”。设备重启关闭热点，并使用保存的配置联网。需要时重新连接设备热点查看进度。

不接管理台时无需填写 MQTT。可展开“管理台连接（可选）”填写已部署 NEXUS 的 MQTT/TLS 地址、设备 ID、用户名、密码和可选 CA；该入口不替代服务端设备注册/ACL。已有 NEXUS 身份不能通过此处更换。

后续修改：主页长按 BOOT 打开菜单，短按选择“网络设置”，长按执行；设备重启进入设置窗口。配网时长按 BOOT 2 秒可返回宠物。窗口默认限时 **15 分钟**（可在热点设置改为 5–60 分钟），退出或超时保留已保存凭据和成长存档，并记住本次离线选择，避免每次开机强迫配网。家庭 Wi-Fi 临时故障不会自动开放热点；通过菜单重新进入。

## 当前状态（默认展示）

进入设置页无需展开任何折叠项，首屏就是“当前状态”。三块信息分别来自运行状态与已保存配置，只读：

| 区块 | 展示内容 | 数据来源 |
| --- | --- | --- |
| 家庭 Wi-Fi | 名称、连接状态（已连接 / 已保存未连接 / 未配置）、IP、子网掩码、网关、DNS、信号与信道、地址获取方式、主机名 | `net` 凭据组 + `esp_netif_get_ip_info`、`esp_netif_get_dns_info`、`esp_wifi_sta_get_ap_info` |
| 设备热点 | 当前名称（隐藏时直接标注）、名称来源（自定义 / 默认随机）、安全形态、信道、最多连接设备、当前连接设备数、剩余设置时间 | 实际 AP 配置 + `esp_wifi_get_channel`、`esp_wifi_ap_get_sta_list` |
| 管理台 | 设备 ID、Broker 主机与端口、是否 TLS、脱敏设备账号、是否使用自定义 CA、配置状态 | `nexus` 凭据组的只读摘要 |

空状态与歧义都写明，不用“看起来正常”的占位：未保存家庭 Wi-Fi 时该块提示“尚未保存家庭 Wi-Fi”，并指向下方第 1 节；未配置管理台时提示“尚未接入管理台（可选）”；Broker 读不到时显示“未读取到地址”；Wi-Fi 已保存但当前没连上时状态写“已保存，当前未连接”，不显示任何在线标记。

设置模式下不建立 MQTT 连接，因此管理台一栏只报告已保存的配置，状态固定为“配置已保存（设置模式不连接 Broker）”，不冒充在线。Broker 只显示 `host[:port]`，URI 里的账号、口令和路径全部丢弃；设备账号只保留首个字符（按 UTF-8 字符边界，不会截出乱码）再加 `***`；热点口令、Wi-Fi 密码、WSS token、CA 内容一律不下发页面。

## 设备热点设置

页面第 2 节修改的是设备自己的热点，与家庭 Wi-Fi 相互独立：

| 设置 | 取值 | 说明 |
| --- | --- | --- |
| 热点名称 | 自定义 1–32 字节，或默认 `Qitomo-XXXX` | 默认每次进入重新随机生成；自定义后固定使用 |
| 热点密码 | 每次随机 12 位 / 固定 8–63 位 / 开放网络 | 开放热点须在页面勾选确认；已保存的口令不回显，留空表示沿用 |
| 隐藏名称 | 开 / 关 | 开启后手机需手动输入名称，仍可访问 `http://192.168.4.1` |
| 信道 | 1–13 | 与家庭 Wi-Fi 或其他热点冲突时可换 |
| 最多连接设备 | 1–4 | 默认 2，与原来一致 |
| 设置窗口 | 5–60 分钟 | 默认 15 分钟；超时退出并保留已保存内容 |

保存只写 NVS 偏好 `pet_setup/portal_v1`，不触碰 Wi-Fi/小智/NEXUS 凭据的 revision，也不改写当前热点；**下次进入设置**才使用新值。点“保存并重开热点”会保存偏好并以设置模式重启，约 20 秒后手机需用新名称重新连接（名称与口令见屏幕）。偏好缺失时用默认随机热点；内容损坏时同样回落默认，不删除家庭凭据，也不阻断配网。

热点名称和密码在局域网内并非秘密，开放热点更是任何附近设备都能连接并访问设置页，因此只在需要调试时使用开放模式。密码仍只出现在设备屏幕和用户自己的输入中，`/api/state` 与诊断只返回名称、密码策略和安全形态。屏幕为 240×320，名称按两行省略号显示，密码最多显示 24 位，完整值以用户设置为准。

家庭网络仅支持 2.4 GHz 开放网络或 WPA2/兼容网络，不支持企业认证；密码为空表示开放网络，非空需 8–63 字节或 64 位十六进制 PSK。设备热点同样只提供开放或 WPA2。不存在自动弹出网页的保证，始终可以手动输入上述 IP。

## 家庭网络高级设置（可选）

第 1 节下方默认折叠的“家庭网络高级设置”用于固定地址与主机名，日常保持自动获取即可：

| 设置 | 取值 | 说明 |
| --- | --- | --- |
| 地址获取 | 自动获取（DHCP，默认）/ 固定 IP | 切回自动获取时不保留旧静态字段 |
| IP 地址、子网掩码、网关 | 点分十进制四元组，各 1–15 字符 | 掩码须为连续 1，网关须与地址同网段 |
| DNS | 同上，可留空 | 留空沿用网关作为解析入口 |
| 主机名 | 字母/数字/连字符，最长 32，首尾不能是连字符 | 用于路由器 DHCP 列表识别设备 |

固定地址与凭据同源校验：页面先做格式检查，`POST /api/network` 再按 `pet/netcfg.h` 的共享规则复核，`svc_config` 提交 `net` 分组时同样复核，任一层不通过都拒绝写入。保存写 `net` 分组的 `ip_mode/ip/netmask/gateway/dns/hostname` 并回读，**下次联网生效**，不立即断开当前连接；设置模式下同时把新地址应用到当前 STA 接口，再点“连接并保存”即按新地址联网，便于当场验证。填错会导致设备连上 Wi-Fi 却无法访问网络，此时重新进入网络设置改回自动获取即可，热点本身不受影响。

页面顶部“当前地址”一行只读显示已连接时的 IP、网关、DNS、信号和信道，来自 `esp_netif_get_ip_info`/`esp_wifi_sta_get_ap_info`，不含密码，也不代表固定地址已生效。诊断 `setup` 只记录“是否固定地址”和主机名，不输出地址值。

## 使用语音唤醒

安装 [voice 预设](13-operational-software.md)及配套模型后，先等主页显示正常时间，确认联网对时完成。回到宠物主页说完整的“小爱同学”，出现“正在听”后提问，说完停顿，由设备自动结束录音并播放回答；回答结束后可再次唤醒。BOOT 的“按住说话”仍保留。静音、免打扰和播放回答时暂停麦克风采集，当前不支持播放中的语音打断。

## 绑定与凭据边界

设备通过启用证书验证的 HTTPS 请求固定官方入口 `https://api.tenclass.net/xiaozhi/ota/`，使用 STA MAC 和独立持久化 client UUID。等待真实 SNTP 时间后发起请求，单次超时 5 秒、绑定轮询限时 5 分钟。响应必须提供合法数字绑定码或完整 `wss://` 连接信息；WSS URI/token、设备身份写入私有 NVS，不要求用户粘贴令牌。当前支持官方 `Activation-Version: 1` 与 WSS 配置，不支持需要 eFuse/HMAC 的另一种激活方式，也不把只有 MQTT 配置的响应假装成语音就绪。

官方入口名称含 `ota`，本功能只读取绑定和语音连接配置，**不下载、不烧写供应商固件**，响应的 `firmware` 字段不参与升级。正式 OTA 继续使用原有受控流程。协议参考为[小智官方固件实现](https://github.com/78/xiaozhi-esp32/blob/main/main/ota.cc)；真实官方平台响应和语音对话必须另行验收。

Wi-Fi、小智和 NEXUS 分组独立提交，沿用 `pet_provision/bundle_v1` 的 revision/CAS、完整校验、原子写入及回读。修改一组保留其他组；旧 namespace 凭据仅在尚无 bundle 时完整迁入，存在但不完整的旧分组拒绝覆盖。原 USB 全量 provision 继续要求 `net` 和 `nexus`；热点可只保存 `net`，此时正常模式启动 Wi-Fi/SNTP，NEXUS MQTT 保持禁用。仅 Wi-Fi 不意味着语音或管理台已经可用。

服务端密码、Wi-Fi 密码、WSS token、原始配置和录音均不写入 Git 或诊断输出。本机模板仍可用于维护，日常设置优先使用热点。

## 本地 HTTP 契约

HTTP 仅绑定 SoftAP 接口，固定 Host `192.168.4.1`（可带 `:80`），不在家庭网络接口提供配置服务。无跨域许可；写请求要求匹配 Origin、随机 128 bit 会话 nonce 和当前 `expectedRevision`，JSON 最大 10,000 字节，拒绝未知/重复字段、深层 JSON 和不完整请求。配置和激活任务排队到独立拥有者，UI/HTTP 回调不执行 Flash 写入或长时间联网。

| 接口 | 行为 |
| --- | --- |
| `GET /` | 内置离线页面，无 CDN/外部脚本 |
| `GET /api/state` | 状态、revision、窗口时间、保存标记、短期绑定码、当前热点名称/是否开放/安全形态/信道/客户端数、已保存热点偏好（不含口令）、已保存 Wi-Fi 名称、`net` 地址设置与当前 STA 地址/信号（只读）、管理台摘要（设备 ID、Broker 主机、TLS、脱敏账号、是否自定义 CA）及页面会话 nonce；不返回已保存密码/token |
| `GET /api/scan` | 最多 20 个网络；SSID 按文字显示 |
| `POST /api/wifi` | `expectedRevision/ssid/password`；取得 IP 后保存 |
| `POST /api/services` | `expectedRevision/nexus`；仅更新 NEXUS 分组 |
| `POST /api/network` | `expectedRevision` 加 `ipMode`（`dhcp`/`static`），`static` 时 `ip/netmask/gateway` 必填、`dns` 可选，`hostname` 可选；仅更新 `net` 分组的地址字段 |
| `POST /api/portal` | `expectedRevision/portal{version,custom,ssid?,passwordMode,password?,hidden,channel,maxClients,windowMinutes}`，可选 `restart:true`；保存热点偏好，必要时重启进入设置 |
| `POST /api/activate` | `expectedRevision`；连接官方平台并保存完整 WSS 分组 |
| `POST /api/finish` | `expectedRevision`；保留凭据并重启返回主页 |

错误会显示失败状态，允许重试；处理中禁用重复提交，退出仍可用。revision 冲突先重新读取状态，不能直接覆盖。热点偏好请求另限 512 字节，网络地址请求按固定字段白名单解析，字段与 NVS/凭据编解码共用同一套校验。`PET_DIAGNOSTICS` 中的 `setup` 只包含状态编号、错误码、revision、剩余时间、保存标记，热点偏好的自定义/密码策略/隐藏/信道/连接数/窗口，以及是否使用固定地址和主机名，不包含热点名称、热点密码、IP 地址、nonce 或家庭凭据。

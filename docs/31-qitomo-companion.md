# 31 · 栖团电子伙伴

2026-11-24 接受的产品方案；实现与验证逐项记录于 docs/18。

## 产品与输入基线

栖团是浅瓷白外壳、墨绿面罩、薄荷绿眼睛、猫耳天线与尾灯的电子精灵。主页是小舱，完整属性收进成长页。三实体按键是发行标准：A 确认/动作，B 下一项/长按返回，C 语音/长按静音；摇杆显式启用、只是便利增强，三键可以完成全部核心功能和小游戏。BOOT 保留维护入口。

六类入口：互动、游乐场、小舱、成长、陪伴、设置。菜单使用可见相邻项和列表，保存后不跳回主页。重要状态、隐私和失败提示不得被装饰覆盖。

## 内容与玩法

- 接星屑：45 秒三轨道，B 换道，A 护盾；摇杆左右直接换道。
- 信号接力：五轮图形记忆，B 选择，A 确认；声音关闭仍可玩。
- 轨道对接：五次机会，B 改方向，A 锁定；最长一分钟。
- 普通消息延后，重要消息/语音/输入故障暂停游戏，主动恢复后继续。
- 游戏结果由设备统一提交，沿用玩耍奖励、冷却、精力限制；练习不重复发奖励。
- 轻养成取消离线饥饿/精力惩罚、冷落扣亲密与疏于照料降健康；原低健康通过在线休养恢复。
- 六件穿戴、六件摆件，三个主题和三个固定摆放位；不做付费抽取。
- 回忆记录真实里程碑，不保存声音或私人对话。设备拥有数值与解锁的最终决定权。

## 两端边界

管理台提供伙伴空间、衣橱/小舱预览、回忆与收藏，保留消息、设备、投递、自动化、权限和 CORE 独立专注档案。仅管理员可应用外观；离线只存草案。请求必须带设备版本与幂等身份，设备落盘确认后才表示应用成功。不会远程加经验、金币或解锁内容。

## 存档与收藏契约（PET-SAVE-01）

v5 存档为 256 字节、CRC32、双槽提交；兼容读取 v1/v2/v3/v4。旧固件看到未知版本必须拒绝覆盖；回退固件前应保存原备份。104–252 字节以固定小端字段保存收藏、三个游戏纪录/次数、专注次数、外观、版本、最近命令身份和八条回忆；253–255 为保留零。正常在线消耗、每日任务、游戏奖励冷却保持；离线只恢复睡眠精力并推进冷却，不扣状态。

本地购买、换装和游戏结算走成长服务单一锁与双槽提交。购买价格/条件由设备目录决定；游戏冷却或低精力时仍记成绩但不发重复成长奖励。外观请求只接受已拥有内容及已开放主题，需匹配 appearance_revision；远端身份只允许换装。回档保留已消费身份、收藏和纪录，且不退还已花金币，避免旧备份重复兑换。
